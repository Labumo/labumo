# Labumo

Labumo — kuriamas pagalbos, mokymo ir veiksmų asistentas svetainėms bei programoms.

Numatoma patirtis: asistentas padeda pagal verslo patvirtintas žinias, pasiūlo atlikti
konkretų veiksmą ir prireikus perduoda tą patį pokalbį žmogui. Kiekvienas produktas
galės pasirinkti savo dizainą, asistento vardą ir personažą.

Technologinė kryptis — Kotlin Multiplatform, Compose Multiplatform ir Kotlin/Wasm.
Pirmoji integracija planuojama 24mods platformoje.

## Būsena

2026-10-13: produkto pradžia. Šiame repo kol kas yra tik viešas pristatymas;
veikiančio SDK, serverio ar diegimo paketo dar nėra. Aprašytos galimybės yra planas.

pareiškimas, kad visas Labumo produktas jau išleistas kaip open source.

Pagrindinis produkto domenas — `labumo.com`; svetainė dar ruošiama.
