# Labumo viešo repo taisyklės

- Šiuo metu repo skirtas viešam pristatymui. Nepublikuok privataus produkto kodo,
  komercinių planų, klientų informacijos, prisijungimų ar infrastruktūros duomenų.
- Viešo kodo apimtis ir licencija dar nepasirinktos. Nepridėk licencijos ir nevadink
  viso produkto open source be savininko sprendimo.
- Po pradinio repo sukūrimo kiekvienam pakeitimui naudok atskirą worktree,
  `codex/` šaką ir PR. Merge ir leidimas — tik pagal žmogaus pavedimą.
- Viešas kūrimo ar naudojimo kelias neturi reikalauti prieigos prie privačių repo,
  privataus Software Factory leidinio ar savininko PR Review paslaugos.
- Dokumentacijai patikrink faktus, vietines nuorodas ir `git diff --check`.
  Kodo patikras nustatys pirmas realizacijos PR; šiuo metu programos testų nėra.
- Žmogui skirti dokumentai ir PR lietuviškai. Viešas klaidas galima registruoti
  šio repo Issues; jose negali būti privataus palaikymo pokalbių ar klientų duomenų.
